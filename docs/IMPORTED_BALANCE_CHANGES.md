# HollowKnight 数值与机制候选 v0.6.6-balance.1

目标是接近原版角色强度，同时保留骨钉多段、灵魂法术、伙伴指令三条路线。以 `v0.6.5-recovery.2` 为对照，保留 11／33／99 的灵魂节奏，保留前一轮真实付款、重放、伤害来源和预览纯度修复。当前是第一轮可测试候选；数值判断来自代码和组合收益分析，尚无整局胜率数据。

适配本机游戏 public-beta v0.111.0（commit 41cef1ea）、BaseLib v3.4.7。原订阅包与之前的恢复包均保留，当前构建不自动安装到游戏或上传工坊。

## 机制与显示

- 法术蓄力 Spellcharge、神龛祝福 ShrineBlessing 仅由**攻击法术**消耗；治疗、回魂和抽牌技能继续保留加伤，技能仍能积累法术蓄力。
- 灵魂暴君 SoulTyrant 标为不叠加；每次法术击杀仍获得 1 能量、抽 1，每回合至多 2 次。原奖励本就固定，避免重复叠层造成错误预期。
- 盘绕骨钉和锐化骨钉 SharpenedNail 不会把原本 0 段的攻击变成一次免费攻击；锐化骨钉保留当回合奖励，等下一次有效骨钉攻击使用。
- 溢魂斩 SoulUnbound、锋锐突袭 SharpAssault 的描述使用游戏的计算伤害变量，预览包含灵魂档位或连击加成。实际攻击在出牌时取一次伤害快照，所有额外段使用相同基础伤害。
- 中英文卡牌、状态与伙伴提示同步。消耗关键词由游戏根据卡牌关键词追加，避免描述重复。

## 组合收益示例

这些例子只说明改动方向。产魂按初始遗物捕魂者 SoulCatcher 的每次有效命中 11 灵魂计算，假设没有触及 99 灵魂上限；不计其他遗物、易伤、附魔等额外修正。

- 快速劈砍 + 普通不碎之力 + 一层盘绕骨钉：原基础伤害 `(3+3)×3=18`，产生 33 灵魂；现在 `(4+2)×2=12`，产生 22 灵魂。额外骨钉段与产魂特色仍在。
- 蓄能骨钉以 1 能量打出 3 段、产生 33 灵魂；魂能流转可返还 1 能量并抽牌，配合魂之回响可能重新抽到循环组件。流转现在消耗，使这一组相同卡牌无法反复循环。
- 魂壳涌现持有 33／66／99 灵魂时，基础格挡由 33／66／99 调为 **16／33／49**。
- 8 生命伙伴的织壳庇护仍给 16／24 基础格挡；24 生命伙伴由 48／72 限制到 **30／45**。
- 溢魂斩在 33／66／99 灵魂时仍造成 30／45／60 基础伤害，升级为 35／50／65；锋锐突袭仍为门槛前 5／7、门槛后 10／12。此次改善显示，不提高这些伤害。

## 验证与试玩

自动验证说明和运行命令见 [tests/README.md](tests/README.md)，当前结果见 `validation/balance-interaction-tests.json`；编译、源码差异、资源和分发校验见 `validation/verification-summary.json`。`core-*` 验证文件属于 v0.6.5-recovery.2 的历史记录。

测试直接调用真实模组方法，但使用独立进程、最小战斗状态及引擎边界替身。它验证数值、付款、预览、攻击命令参数和钩子规则，不能证明完整战斗、动画、存档继续、联机或整局平衡已通过。

试玩时先确认模组列表为 `v0.6.6-balance.1`。在独立测试存档分别试骨钉、法术、伙伴路线，记录关键卡、回合数、灵魂收支、损失与回复生命。重点检查：

1. 聚神与流转打出后进入消耗堆；灵魂不足、免费自动出牌和重放继续正确付款。
2. 治疗技能不吞法术加伤，随后攻击法术的每段伤害与预览相符。
3. 连击在打出前恰为 3 或 4 次时，额外段伤害保持同一个出牌快照；溢魂斩在 32／33／66／99 灵魂时显示与结算正确。
4. 重复召唤到 24 生命后，最大生命不再增加、当前生命仍回复；牺牲、承伤溢出、死亡爆炸和成熟时序继续正常。
5. 完成战斗、保存退出并继续。最后结合几局实战记录微调，避免仅凭一张卡的纸面效率判断整套角色强度。
