- **骨钉线**：命中产魂，利用多段、骨钉增伤及剑技蓄力提高收益。强力劈砍、旋风劈砍、冲刺劈砍三张签名剑技继续支撑蓄势待斩、傲慢印记和钉师之耀。
- **灵魂线**：骨钉提供资源，法术负责输出、抽牌与资源转换；存魂增伤与花魂爆发之间保留取舍。聚神、深凝承担治疗，魂能流转、灵魂图腾承担魂转能。
- **虫群召唤线**：保留三类伙伴及召唤、指令、生命成长、牺牲和回收配套。格林仪式与格林之子分别提供重复召唤及永久强化；织丝连袭与虫群追击分别提供多段启动及连携收尾。
- **配合工具**：格挡继续服务生存、血胆之茧产魂及召唤防护；甲壳回响、吐纳、焚魂契约与消耗牌联动；崩壳痛击、受难之歌、痛楚烙印和堕落之怒保留自伤、受伤及低血收益。

五张中毒牌整体退出，避免只删除中毒来源或终结技而留下无配套卡。壳击和固若金汤退出后，不再单独奖励永久囤积格挡转输出；普通防御仍然保留。

## 存档与归档边界

十八张旧卡源码及中英文本保存在 `archive/retired_cards_20261028/`，其中 `retired_cards.json` 记录旧 ID、替代 ID、退役原因和每份源码的 SHA-256。归档不编译成现役卡牌模型。旧卡图像保留为历史资源；图像存在不代表旧卡仍会进入奖励、商店或图鉴。

`RetiredCards` 继续只匹配小骑士卡牌类别下的完整旧 ID。原生反序列化入口在内存中将旧 ID 转换为现役卡 ID，再由原生逻辑恢复升级、附魔、保存属性和入牌组楼层；下一次保存使用现役 ID。不扫描或直接改写玩家存档文件。

替代卡采用当前费用和效果，以下差异会直接改变旧牌组玩法：

- 魂能激涌 → 魂能流转、虚空吞噬 → 灵魂收割均引入基础 **33 灵魂**付款。前者不再免费加速，后者不再永久增加最大生命。
- 残像 → 甲壳回响由每次出牌触发改为卡牌消耗触发。
- 淬毒之锋 → 盘绕骨钉由可叠加的中毒能力改为不叠加的额外打击；多张旧卡转换后不会叠加盘绕效果。
- 固若金汤 → 梦之盾、虚影形态 → 影披风会改变卡牌类型和防御方式。旧中毒、壁垒牌组也不会保留原构筑功能。

特意保留 `FragileStrengthPower`、`DefenderCrestPower`、`NailEnvenomPower`、`WispAfterimagePower`、`VoidSurgePower` 五个能力模型及其双语文本、图标，以保留历史已生效能力状态对应的模型。它们没有现役卡牌入口。此兼容保留不等于已验证完整战斗中读档；旧卡 ID 迁移、历史能力模型可解析和完整战斗恢复应分别验证、分别报告。
