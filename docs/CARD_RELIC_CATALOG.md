# 小骑士全部卡牌与遗物效果 — v0.6.7

共 **83 种现役卡牌**：2 张基础卡、80 张奖励池卡、1 张衍生牌；**25 件遗物**。已发布到 [Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3796063046)。

表中数值不计战斗中的力量、增伤、费用折扣或敌方状态。魂表示灵魂；X 表示消耗全部当前能量。每次有效骨钉命中，初始遗物捕魂者提供 11 灵魂；灵魂基础上限 99。

新召唤流规则、伙伴特性和连携说明见 [虫群召唤流设计](SUMMONING_DESIGN.md)。
