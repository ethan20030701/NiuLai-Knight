# 魂量费用穿透放大卡牌修复 — v0.6.6-test.8

## 原因与改动

`NSoulCostBadge.ZIndex = 5` 使牌组列表中的费用角标越过原生卡牌查看窗口，盖在放大卡牌的标题或说明文字上。它不是正文中的新增费用，而是后方卡牌的角标穿透。单卡位置测试没有覆盖多个卡牌与弹窗共同渲染的场景。

费用角标恢复为原生费用控件的相对层级0，并放在 CardContainer 内 StarIcon 之后的兄弟位置。保留 test.7 的95%不透明原作图标、粗体数字、位置与费用颜色；魂量计数和血条布局保持 test.7 的实现。

## 验证

- 实例化原生 `inspect_card_screen.tscn`，在后方放置扣魂卡，使其角标位置与放大卡牌的说明区域重合。
- 比较显示/隐藏背景卡牌时，放大卡牌说明区域对应像素是否一致。旧 test.7 的像素检查失败，截图清楚复现正文上的多余33；新 test.8 同一区域像素一致。
- 原生打开、左右切牌、升级、切换至非扣魂牌、关闭查看窗口均检查。正式版0.107.1与本地beta0.111.0各95项界面检查通过，覆盖21张扣魂卡。
- 本次只调整绘制层级与节点顺序，没有修改战斗支付或数值规则，沿用 test.7 的19项双分支战斗与6项HUD回归基线。
