# v0.3.6 更新公告 / Update Notes

## 中文

**《空洞骑士》小骑士角色 Mod v0.3.6 — 数值平衡轮**

对标原版角色卡牌数值基准（打击 6/1、双持 5×2、回声斩 10 AOE、钝击 32/3 等）全面校准：

- **快速劈砍**：8 点伤害 → **3 次 3 点伤害**（升级每段 +1，共 12）——快速连砍就该是多段！额外多 3 次产魂判定
- **蓄能骨钉**：3×3 → **4×3**（12 总伤），多段流引擎此前偏低
- **大斩**：16 → **18**
- **旋风斩**：5 → **8** AOE（原版同位回声斩是 10）
- **钉气冲击**：技能牌 → **攻击牌**（剑技家族统一为攻击牌），7 → **8** AOE；气浪依然不产魂
- **冲刺**：6+6 → **7+7**
- **深渊尖啸**：20 → **24** AOE
- **暗影之魂**：30 → **32** 单体 + 12 溅射
- **梦之钉**：3 → **6** 伤 + 抽牌

> **需要前置 BaseLib (v3.4.7+)**。欢迎反馈！

## English

**The Knight — Hollow Knight Character Mod v0.3.6 — Balance Pass**

Calibrated against vanilla card benchmarks (Strike 6/1, Twin Strike 5x2,
Echoing Slash 10 AOE, Bludgeon 32/3):

- **Quick Slash**: 8 damage → **3x3 damage** (upgrade +1 per hit, 12 total) —
  rapid slashes are multi-hit now, with 3 SOUL-gathering strikes
- **Channelled Nail**: 3x3 → **4x3** (12 total)
- **Great Slash**: 16 → **18**
- **Cyclone Slash**: 5 → **8** AOE (vanilla Echoing Slash is 10)
- **Nail Shockwave**: Skill → **Attack** (nail arts are all attacks now),
  7 → **8** AOE; the wave still gathers no SOUL
- **Dash**: 6/6 → **7/7**
- **Abyss Shriek**: 20 → **24** AOE
- **Shade Soul**: 30 → **32** single target + 12 splash
- **Dream Nail**: 3 → **6** damage + draw

> **Requires BaseLib (v3.4.7+)**. Feedback welcome!
