# v0.6.4 bug 核查与修复

## 旧骨钉卡住的原因

v0.6.3 使用 public-beta v0.111.0 的程序集编译。该分支的 `AttackCommand.FromCard(CardModel, CardPlay)` 在正式版 v0.107.1 中不存在，正式版只有 `FromCard(CardModel)`。攻击卡执行时发生 `MissingMethodException`，原生出牌流程因此中断，卡牌留在出牌区。

v0.6.4 改为正式版编译，并集中适配两个分支的攻击、伤害、消耗及加法伤害钩子。移除 `CardPlay.Player`、`AttackCommand.CardPlay` 等正式版不支持的直接引用。构建脚本默认使用正式版依赖。

## 同时修复

| 问题 | 修复 |
|---|---|
| 无忧旋律阻止死亡后仍为 0 生命 | 真正恢复至 1 生命，再消耗安眠并给予 22 格挡。 |
| 影披风未正确消耗，可能持续免伤 | 只在敌方攻击突破格挡时触发，消费一次闪避，并正确结算锋利之影。 |
| 技能蓄力、法术蓄力在多段/群体攻击中丢失或遗留收益 | 在出牌前记录本次收益，各段共用；预览无副作用，结算及回合开始清理。 |
| 骨钉大师荣耀的预览会消耗首次奖励，后续段没有加成 | 在真正出牌时确定首次剑技，各段完整获得 8 点加成。 |
| 饱满灵魂的预览不显示加成，多段可能重新判断门槛 | 按出牌前灵魂量记录门槛，本次各段一致；预览按当前余额显示。 |
| 孵化小虫死亡爆炸没有伤害 | 使用存活的主人作为原始伤害来源，避免原生伤害命令拒绝已死亡的伤害来源。 |
| 深渊尖啸对单体多算一个敌人 | 全体攻击按存活敌人数减一计算「其他敌人」。 |
| 部分能力/遗物使用其他玩家卡牌触发效果 | 补上持有者检查；织者之咬增伤限定自己的有效攻击。 |
| 无敌人时格林之子随机选择空列表 | 检查可命中敌人后再选择。 |
| 召唤牌在无持有者的预览中读取伙伴 | 查询允许空持有者，红色不可打出提示限定战斗。 |
| 护育虫群遍历过程中宠物列表可能变化 | 使用存活伙伴快照。 |
| 文本数值、升级效果与代码不符 | 校正灵魂容器、骨钉大师荣耀、傲慢印记、安眠、织者之歌、影披风和脆弱之力的中英说明。 |

## 验证

- 正式版依赖构建：**0 警告、0 错误**。
- DLL 中 **259 个直接游戏/BaseLib 接口引用**逐项解析，两个分支均无缺失。
- 两个分支各 **19 组原生引擎回归检查，0 失败**。测试调用游戏自身的资源支付与完整 `OnPlayWrapper`，核对卡牌确实离开出牌区。
